# 长期任务说明

用于在目标项目形成任务约定。按实际需求填写并移除说明文字；不把本模板直接作为已经获得授权的任务。

## 目标与成果

- 项目与任务身份：沿用或新建的任务 ID、现有运行入口。
- 长期维护目标：要持续维护的事物及其用途。
- 单轮成果与合格标准：交付什么、证据要求、无变化时如何记录。
- 停止条件：用户停用，或需宿主额外实现的结束条件。

## 输入与工作记录

- 允许的资料来源、更新方式、可读取范围。
- 历史成果、人工决定与下一轮记忆如何使用。
- 允许写入的路径、结果采纳方式及共享输出的写入责任。

## 运行与人工决定

- 触发方式、时区、首次到期与间隔；区分固定间隔和上轮结算后等待。
- 每周/单轮限制，执行与排队期限。
- 审核方式与责任人、渠道、等待期限、超时策略及是否允许重审。
- 对外通知的需求与所选版本实际支持程度。

## 异常、变更与维护

- 失败、核验冲突和无新结果时的处理方式。
- 改动何时作用于未来回合，已有冻结回合如何保留。
- 暂停新回合、恢复、停用与取消在途工单各自如何操作。
- 所需执行能力、待接入能力、运行入口与后台归属。

## 授权与验收

- 用户已授权的具体范围；未确定的重要事项。
- 当前交付阶段：设计、草稿、已启用、已部署或已验证运行。
- 真实验证与离线验证分别记录；结果、记录位置与仍待处理事项。
